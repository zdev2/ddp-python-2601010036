## Latihan tambahan (folder `others/`)
1. others/convert_decimal_binary.py: konversi bilangan desimal ke biner dan sebaliknya secara manual, dibandingkan dengan fungsi bawaan Python
2. others/fileSorter.py: memindahkan file foto (.jpg/.jpeg) dari folder `origin/` ke folder `target/`
3. others/studycase_tiket_bioskop.py: studi kasus sistem kasir tiket bioskop (harga per studio dan hari, gratis 1 tiket tiap pembelian 5 tiket, rekap penjualan)

## Cara menjalankan

```
python latihan2_persegi_panjang.py
python latihan3_konversi_suhu.py
python latihan4_total_belanja.py
```

Latihan tambahan dijalankan dari folder `others/`:
```
cd others
python convert_decimal_binary.py
python fileSorter.py
python studycase_tiket_bioskop.py
```

Catatan: `fileSorter.py` membutuhkan folder `origin/` yang berisi file foto. Folder `target/` dibuat otomatis jika belum ada.
